# 论文查重（第一次个人编程作业）

> 作业 GitHub 链接：**【推送后请把这里换成 <https://github.com/xxyyll0323/3224004083>】**

学号 **3224004083**　｜　语言 **Python 3（零第三方运行时依赖）**

给定一份原文和一份在这份原文上经过**增、删、改**得到的抄袭版论文，计算两者的
重复率，并把结果（`[0,1]` 浮点数，保留两位小数）写入指定的答案文件。

---

## 一、快速开始

```bash
# 进入学号目录（main.py 在这里）
cd 3224004083

# 运行：三个参数都是文件的绝对路径，顺序不能换
python main.py <原文文件> <抄袭版论文文件> <答案文件>

# 示例
python main.py sample/orig.txt sample/orig_0.8_dis_2.txt answer.txt
cat answer.txt        # 形如 0.94
```

程序**不在终端打印结果**，结果只写进第三个参数指定的文件。

**参数顺序**（写错顺序结果就没有意义）：

| 位置 | 含义 |
|---|---|
| 第 1 个 | 论文**原文**文件的绝对路径 |
| 第 2 个 | **抄袭版**论文文件的绝对路径 |
| 第 3 个 | **答案**输出文件的绝对路径 |

**退出码**：`0` 正常 ／ `1` 运行期错误（文件不存在、路径是目录、文本为空、答案不可写，
此时已有答案文件保持原样）／ `2` 参数个数不是三个。

## 三、算法一览

```text
原文 / 抄袭版论文
        │
        ▼
   reader.read_text      按编码读入 → 去 BOM → NFKC（全角转半角）→ 剥离 HTML 噪声
        │
        ▼
   normalize             只保留字母、数字与汉字，字母转小写
        │
        ▼
   count_ngrams          切成 n = 1,2,3,4 的相邻字符片段，统计频次
        │
        ▼
   cosine_similarity     每阶算一次余弦：Σ A×B / (√ΣA² × √ΣB²)
        │
        ▼
   ngram_similarity      按 0.30 / 0.30 / 0.25 / 0.15 加权平均 → [0,1]
        │
        ▼
   writer.write_answer   格式化为两位小数写入答案文件
```

为什么这样设计：

* **字符 n-gram**：中文没有天然分词边界，用相邻字符片段当"指纹"就不需要词典，
  中英混排也能直接处理，且不引入第三方依赖；
* **用频次而不是"是否出现"**：`aaaa` 里的 `aa` 出现 3 次，频次要参与计算，
  否则重复段落会被抹平；
* **与顺序无关**：n-gram 频次是全文统计量，所以段落顺序被打乱时相似度不会塌，
  正好满足"能处理段落顺序发生变化的相似内容"；
* **多阶加权**：短片段对局部改写敏感，长片段对无关文本更有区分度，两者互补；
* **不用 SimHash**：它靠"降维 + 海明距离"给出近似指纹，判定阈值藏在海明距离里不好
  调试；本题文本量很小，用不着近似检索，而余弦每一步都能手算验证。

三种相似度度量的实测对照见 `docs/metric_comparison.txt`。

## 六、异常处理

| 场景 | 处理方式 | 退出码 |
|---|---|---|
| 参数个数 ≠ 3 | 打印用法 | 2 |
| 输入文件不存在 / 是目录 / 路径为空 | 提示，并保护已有答案文件 | 1 |
| 输入编码无法识别（UTF-8/GB18030/UTF-16 都失败） | 提示已尝试的编码 | 1 |
| 文本没有任何有效字符（空文件、纯标点） | 提示"没有可比较的有效文本" | 1 |
| 答案路径是目录 / 上级目录不存在 | 提示并拒绝写入 | 1 |

程序保证**不会抛出未捕获的异常堆栈**退出。
